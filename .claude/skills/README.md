# Agent skills

Instructions an AI coding agent (Claude Code) loads for a task in this repository. Each folder holds a `SKILL.md`.

| Skill | Use it to |
|---|---|
| [finish-change](finish-change/SKILL.md) | Check that a change has its tests, save/restore coverage, KnownDifferences and CLAUDE.md updates, and a clean build before a commit |
| [work-issue](work-issue/SKILL.md) | Read a GitHub issue (or one full-port item), confirm it against the MDL source, post a plan as a comment, then implement it |
| [make-release](make-release/SKILL.md) | Pick the version, tag, and watch the workflow publish the seven platform zips |
